# 2023 年样刊：可复用的设计观察

后续已完成目录内9期1240页的全刊版式研究，见[覆盖范围与逐期结论](2023-full-corpus-study.md)及[32种设计方法](design-repertoire.md)。以下保留早期抽样记录，适合查具体局部；当前全刊覆盖以新研究为准。

本参考由用户提供的英文版 National Geographic 2023 年 PDF 抽样观察而来。不是官方品牌手册，也不代表逐页研究了全年。页码均为 PDF 页序，不是印刷页码。原文件保留在用户参考资料目录；不将整本刊物或版面截图打包分发到 Skill。

## 版面证据

| 样刊与 PDF 页序 | 实际观察 | 可迁移的方法 |
| --- | --- | --- |
| 202302，34-35 | 折纸鸟跨越对页，黑底保留大块负空间，字的宽度与图像轮廓形成关系；小图注集中在角落 | 先找照片自身的空域，再安排主标题，不为所有标题统一套白色卡片 |
| 202303，8-9 | 显微影像占据对页，栏目名、细线、日期与署名压缩成轻量信息组 | 栏目导航可以精细且低占比，让照片贡献复杂度 |
| 202303，48-49 | 博物馆空间全幅跨页，图注以窄栏直接落在可读区域 | 信息少的摄影页可以很强，但必须由摄影本身支撑；图注不必总放通栏底条 |
| 202305，34-35 | 大象插画、地图、分类比较与引线共同构成解释系统 | 插画应解释照片无法提供的关系；图例、地理和数据必须校验，不以精致视觉代替准确性 |
| 202305，48-49 | 照片跨页，上下及旁侧分别安排正文、窄栏图注与有力度的摘句 | 正文可以较密，同时靠图片尺度、栏宽和摘句建立主次，不把所有页面都做成大留白海报 |
| 202306，8-9 | 深色照片上的白字、细线和小范围强调色；外侧保留纸边 | 深浅反差来自照片条件，文字面板尽量轻；不能为追求同一种风格把所有照片统一压暗 |
| 202307，48-49 | 黑底、极窄的信息栏、线描小插画与大量文字并存 | 专题可有明显不同的阅读密度；中文不能照搬英文极窄栏，应根据汉字阅读调整 |
| 202308，34-35 | 化石大图与圆形局部、指引线、文字解释、复原插画组成结构 | 局部放大与辅助插画要解决具体认知问题；生成复原内容应标明其性质 |
| 202308，48-49 | 地图成为主体，路线、地点注释与航船比较图在同一视觉系统中组织 | 复杂的信息应有主底图、第二层解释与第三层细节，避免随意堆装饰 |

## 本 Skill 的新增执行要求

- 阅读用户参考时先检查文件完整性与页面类型；区分广告、商业内容与编辑页；用户要求时可学习广告的构成方法，但不能把广告排版当成编辑规范。记录文件名、PDF页序与观察结论。
- 分析版面先区分：摄影开篇、阅读页、图像停顿、解释图。建立一张小型跨页节奏表，不要求每个主题机械使用所有类型。
- 图文关系必须随照片变化：检查可用负空间、主体轮廓、视线方向。避免整刊固定左白板右照片或重复卡片覆盖照片。
- 图注作为独立阅读层。优先短窄栏、侧栏或对应编号，注意与正文边缘对齐。文字压图必须在最终尺寸检查对比。
- 正文需要信息密度。允许连续两至三个完整段落、必要的事实摘句、首字或起首短语强调；中文优先可读栏宽，不能照抄英文形式。
- 装饰须有语义：细线帮助分组、点色帮助定位、轮廓或纹理呼应主题。删除对理解和节奏没有作用的符号。
- 可使用 ImageGen 生成概念插画、编辑插画、材质或主题装饰。明确用途、实物依据与自由发挥边界；不要让 AI 图像冒充用户照片、精确地图、已证实的科学复原或实际现场。
- 优先把标注、数字、连线和正文保持为可编辑矢量文字；生成器负责复杂的绘画质感。对插画旁的 AI/示意标注保持清晰但克制。
- 对每张生成素材保留 prompt、生成方式、最终文件与使用位置；生成后复制到项目，检查主题、构图、边缘、错误文字与事实风险。
- 核查细节与缺失事实留在项目制作记录。成品按主SKILL的“主编写作口吻”直接讲述内容，删除“无法确认、本刊不推测”等编辑自述；有依据的判断直接写，不能成立的枝节删去。

## 不可从样刊推出的结论

以上观察不等于得到官方网格、字号或色值。输入 PDF 存在不同尺寸、内容变换与部分黑色补边，不直接把 MediaBox 当作真实印刷开本。不要把参考插画、照片、地图或其文字直接复制进用户新杂志；迁移构成方法并创作自己的内容。


## V4补充观察（2026-11-07）

在原有样本之外，新增查看9、10、11月的6组对页，并定位用户所示7月参考与9月建筑剖面，共9组。页码继续采用PDF页序：

- 202307 PDF22-23：袋狼复育解释跨页，左侧步骤、主体剖面、放大细节、比较与谱系共存；采用层层深入的解释架构。
- 202307 PDF32-33：冰岛照片上的数据轨、白色大数字与窄栏释义；统计与单位构成信息，不只是字形装饰。
- 202309 PDF56-57：建筑剖面与年代、材料及局部放大组织在一起；显示结构图需要资料与时间层次，不是随意“打开建筑”。
- 202309 PDF20-21：左广告右编辑开篇，粗细规则线与巨大字符组织内容；不能把广告归入编辑专题。
- 202309 PDF28-29：左为科学短内容，右为募捐广告；短文可以按证据分块，不必全刊同一正文栏宽。
- 202310 PDF20-21：彩色艺术影像配红色引语和阅读页；强调色服务当期太空主题，照片与文字密度形成对比。
- 202310 PDF28-29：左为航天报道，右为游轮广告；不同阅读目的决定版式密度。
- 202311 PDF20-21：密集正文、圆形定位图与外侧补充栏；信息层级可以通过细线和不同纸色区分。
- 202311 PDF40-41：全幅纪实跨页，窄白字图注放在安静天空中；摄影足够强时不需要额外装饰。
