# 字体、卡片与可读性

## 字体依据

对用户提供202308样刊页面资源递归检查得到字体名称（PDF页序）：19有Geograph、GeographEdit、Earle-Book、GrosvenorBook；44有GeographEdit、GrosvenorBook及斜体；71以GeographEdit组织图解标注；76还有Marden、Daggett和Chisel。27的付费内容页含TiemposText，不能将商业页面字体当作全刊唯一系统。资源名称只能证明这些页面使用了字体，不能据此推出整刊官方字号、授权或使用规范。不得提取样刊嵌入字体用于新作品。

## 中文字体工作流

默认可复现配置、随包字体源、实例化与子集命令见[排版运行时](production-toolkit.md)。先以该配置试排；本页其他字体为设计选择，不是隐式系统回退。替换字体时重做封面与代表跨页样张。

先盘点实际文件、字重、中文字形、许可和PDF嵌入能力，再按角色试排。不要所有角色都用系统默认宋体/黑体，也不要用十种字体制造变化。

- 专题主标题：有力度的黑体重字重，或具有明确风格的宋体中粗字重。按题材选择，不伪造细字体的粗体。建筑、历史可偏宋体；地理探索可偏强黑体；同刊保留稳定的基本组合。
- 长文：适合连续阅读的宋体或明朝体常规字重；图注和导航：黑体Regular/Medium；数字轨：窄体或等宽数字，先检查单位和中英文基线。
- 候选中文开源系列可考虑思源宋体/思源黑体、Noto Serif/Sans CJK。尚未具备时从官方来源获取并核对许可证；不声称已安装。已有可用字体也可以合理使用，不为名称牺牲可读性。
- 用户环境此次检查到NotoSansSC-VF.ttf、微软雅黑、宋体、Arial Narrow、Georgia、Bahnschrift等。只是该环境当时的库存，不作为跨设备必有依赖。可变字体须确认PDF引擎支持；必要时用fontTools实例化目标字重，记录原文件与轴值。
- 字体表写明：角色、字体文件、字重、字号、行距、字距、字形覆盖、许可。替换字体后重新分页和渲染。
- 中文标题可用短英文副题、英文栏目名、拉丁地名或英文期号形成层级；英文必须准确、有语义，通常低于中文主标题的层级。不逐句双语重复，不放无意义英语填空。

## 地方文字

地方原文可以成为封面副题、章节题字、地图地名或小型注记，按主题选择。藏文等具体选词、Unicode、字体、字堆塑形和断行执行[地方文字与地域字体](local-language-typography.md)，不以随机字符或伪文字作装饰。中文、地方原文与英文按信息任务建立层级，避免机械三语重复。

## 专题展示字怎样形成气质

跨年字体索引中，201907 PDF40–41的Turnpike/Marden、202007 PDF39/64的NGEverest、202101 PDF42的NGPictures2020、202211 PDF67的NGTutWedge承担不同专题展示层；长文与图注仍保持清楚分工。这支持“稳定阅读层、定制展示层”的方法，不是要求购买或提取这些字库。PDF抽取字号还受文件页尺寸和转换影响，不当作新刊固定字号。

- 山岳/行进：以高低、疏密、短行与环境尺度形成张力，中文保持完整字形，英文窄体仅承担适合的短词。
- 建筑/考古：由题材材料、年代与形制选择有力度的宋体、衬线或原创题字；题字不直接变成正文，也不为异域感堆仿古符号。
- 年度/日志：可让日期、地点和章节字构成小型索引；数据少时不伪装成密集报纸页。
- 人物/共同问题：从真实观点中提炼少量强调词，用字号、字重、断行组织节奏；不能为视觉效果改写原话意思。

试排真实标题、最长地名、数字单位和一段正文后再定字族。展示字越强，副题和图注越需要稳定。复杂遮挡不应改变阅读顺序。

## 文字容器语法

内容先决定容器，再决定外观。每期选少量稳定样式，不把每句话装进卡片。

| 内容角色 | 可选形式 | 使用注意 |
| --- | --- | --- |
| 关键摘句 | 大字留白、上下短横线、断角线框、细边框与偏移底色 | 必须来自正文真实观点；不是采访引语时不加虚构引号与署名 |
| 背景解释 | 灰白/纸色/主题色侧栏，独立标题和窄栏正文 | 与正文基线对齐，不挤断阅读顺序 |
| 章节开门 | 主色底、短栏目标、强标题、细线和期号 | 形成转场，不机械在每个跨页重复 |
| 图解标签 | 小标题+短释义、细引线、编号点、必要的半透明底 | 尽量贴近对应部位，引线不混淆；字色随局部背景变换 |
| 图中数据 | 大数字、小释义、规则线、窄信息轨 | 字号差有目的，单位与来源不缺失；不把编辑编号当统计 |
| 补充索引 | 薄底色面、页码、缩略图、表格 | 服务导航，不抢主图 |
| 多对象编目 | 图片细框、状态符号、编号与图例 | 框线/符号先定义信息含义；不可让随机边框暗示年代、真伪或等级 |
| 连续地域报道 | 同源侧栏、定位小图、固定比较字段 | 背景随地点更新、正文保持前进；不重复抄录同一段知识 |
| 过程与层次 | 进度短带、阶段标题、重复主体、局部改变 | 每一步应新增信息；不能用装饰进度暗示不存在的完成度 |

用户的金线框参考来自202308 PDF27的付费内容页：浅灰底色与偏移金线框创造层次。可以迁移“底色面与边框错位”的方法，保持与本期配色一致；不默认全刊黄框。

编辑页另有不同依据：201905 PDF72–73的画作边框与符号参与作品状态编目；202011 PDF48的窄侧栏承托定位和数据；202112 PDF8/20的开放信息格连接不同感官入口；202211 PDF68–69的短进度带与层次一一对应。先判断需要分组、比较、定位还是进程，再选择卡片、底色、框线或留白。

## 颜色承担的三种职责

先为本期指定职责：**氛围色**来自场景与材料，**章节色**帮助定位，**数据/状态色**表达变量或历史层次。它们可以共享色相，但不能在同一图里混淆含义。202007的章节色、202012的地图变量、202202的年代/结构标记是不同任务。

同类变量保持图例一致，类别尽量同时用文字、符号或位置区分。主题色可以大胆，照片保留真实的色彩关系；不要为了统一封面而把全刊所有现场调成同一颜色。纸场、色块、实线/虚线和图例均需服务信息。

## 局部背景上的可读性

V4开篇天空上的黑色导语是已观察到的问题：天空亮度不均、云纹与字重相撞，整体看似浅色并不保证局部可读。按下列顺序解决：换到稳定字场、调整字色/字重/字号、局部渐变或色域、独立底色卡。不要只加阴影或细描边敷衍。

逐块检查标题、导语、图注与引线标签所覆盖的全部背景。在100%最终阅读尺寸与缩略图查看，压图文字另做灰度检查。数字化对比度可参考小字4.5:1、大字3:1作为本Skill的辅助门槛，不称为纸刊官方参数；取样须覆盖字下明暗变化，平均值不能代替最差位置的目测。图片变化后必须重验。

将“不可读”作为阻止交付的缺陷；漂亮字体不能豁免。AI生成封面和矢量排字使用同一标准。

202107 PDF68–69的短标题分别在天空用深字、在树冠用白字，说明同一标题也可按语义分组校验局部对比。长句和正文不逐字反色，应换位置或提供稳定字场。参考页同样可能有细小低对比字，不能因为出自样刊而照抄其可读性缺陷。
