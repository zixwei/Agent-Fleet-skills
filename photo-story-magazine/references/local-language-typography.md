# 地方文字与地域字体

## 内容与位置

把地方语言和文字作为主动策划的视觉选项，用真实含义为主题增加地域性；随当地实际语言、对象和内容选择，不机械每期添加，也不把一个地区的多种文化混成一种符号。

适合的位置：
- 扉页或章节开头：原文地名、中文主标题和必要的拉丁转写形成层级。
- 山群、建筑与地图：为少量核心对象增加原文名称，中文保持主要阅读路径。
- 题字与边注：用有出处的当地词语、真实碑刻或手写片段呼应主题；若采用艺术书写，区分原创标题与原始手迹。
- 封面：一处简短原文即可形成识别，不默认中、英、地方文字全部重复一遍。

先说明它为这一页带来什么信息，再安排位置、字重与留白。优先使用地点、人名、物件名或普通词语；经文、真言等只在报道确有相关内容且来源明确时作为引用。外观相近不等于同一种文字，不能以伪文字、乱码或随机宗教符号制造地域气氛。

## 选词与校对

为拟采用的词语记录：原文Unicode、中文含义、具体所指、读音/拉丁转写（必要时）、语言及地方异写、出处与核对结果。根据可靠的双语机构资料、当地原始文字、学术出版物或语言专家核对；机器翻译可辅助查找，不能单独决定复杂地名与文化词语。

短诗或中文创意标题不必强行译成地方文字。没有可靠译文时可用已核对的真实地名形成伴随层级。核查过程留在制作记录，刊内直接呈现文字、含义与必要的精简出处。

## 藏文排版

- 藏文可以用于梅里、香格里拉相关专题，但应与具体地点和对象相符。中文主阅读层保持清楚，原文地名可成为有分量的副题或局部标记。
- 候选字体：Noto Serif Tibetan。获取时读取官方版本与OFL许可，确认本机实际文件及PDF嵌入能力；不把普通中文宋体或“民族风”拉丁字体当藏文字体。
- 藏文存在上下叠字和元音附标，需要实际引擎完成OpenType塑形。字体有这些字符，不等于逐码点绘制就正确。可选择支持相关塑形的浏览器、HarfBuzz/Pango或启用相应塑形的排版路径；导出后检查最终渲染。
- 保持音节内字堆完整，不给每个码点机械加字距，不任意打散或旋转成中文式竖排。短地名优先完整一行；必要断行依音节点与标点规则处理，保留正确符号。
- 行高与字框须容纳上下叠字和附标，按视觉字面与中文配合，不只比较相同point值。检查缺字框、错位附标、断开的字堆、裁切、意外字体回退和文字可读性。
- AI可处理场景与图像融合，准确原文优先由已核对Unicode和排版引擎叠加；生成图中出现的藏文须逐字复核，不能仅凭看起来像藏文验收。

## 梅里示例

| 项目 | 内容 |
| --- | --- |
| 中文名 | 卡瓦格博 |
| 藏文地名 | ཁ་བ་དཀར་པོ་ |
| Wylie转写 | kha ba dkar po |
| 建议位置 | 主峰图鉴标题旁、主峰图注，或以该主峰为题的扉页 |
| 语义对齐 | 指向卡瓦格博这一名称，不充当“梅里十三峰”或“入夜见山”的译文 |

可采用“中文主题标题—藏文主峰名—小号拉丁转写”的层级，按照片字场选择深浅色。若原文已经形成清楚识别，可以省略英文一层；每一种语言都有信息任务。
