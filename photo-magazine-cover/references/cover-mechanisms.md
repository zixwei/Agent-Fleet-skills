# 封面机制研究索引

这里保留跨年研究结论；未提供原刊页面时，先看包内原创成品示例，不把月份与页码当成已看到的视觉参考。

## 2023封面的构图选择

以下来自用户目录内9期封面观察，页序均为PDF1。保留原创刊名和用户指定外框，按主视觉选择构图，不把同一种标题摆法固定到每期。

| 参考月份 | 构图方法 | 迁移条件 |
| --- | --- | --- |
| 02 | 中心物件呈放射结构，短标题退到底部 | 形态本身有力量的器物或材料 |
| 03 | 物件穿入巨大字组，字与主体互相让位 | 可清楚分层的轮廓与简短命题 |
| 05 | 紧裁近景，以纹理、目光与留出的字场建立吸引力 | 细节质量足够，不依赖大全景 |
| 06 | 极高的主标题与山地景物形成纵向张力 | 开阔背景和短词，中文以字重与排列转译 |
| 07 | 微小人物置于巨大环境，短题强化探索问题 | 素材有真实尺度关系与清晰焦点 |
| 08 | 自然浅色表面成为标题字场，深浅形状分区 | 冰雪、墙面、岩面等已有可读区域 |
| 09 | 标志性建筑主导照片，紧凑分行标题靠外侧安排 | 地标与环境有辨识度，避免压住关键形制 |
| 10 | 超大展示字成为封面第二主视觉 | 单一强主题，可与主体保持清楚层次 |
| 11 | 多层短命题与小而明确的技术/人物场景配合 | 主题需要一个清楚主张，副题有具体信息 |

标题与主视觉先在缩略图中比较，再决定字形、断行、遮挡与颜色；边框本身不承担全部设计变化。

## 2019–2022补充：按题材选择封面机制

以下均为相应样刊PDF1。先依据真实素材和主题选择，再制作原创封面；不要求逐个尝试，也不把多图视为必然弱于单图。

|内容主角|可选构图与来源|成立条件与取舍|
|---|---|---|
|人在大地中的行动|微小攀登者/探险者与巨大环境：201902、202204|人物真实可见，尺度关系成立；标题不能盖住关键动作，不凭空补探险经历|
|触感、形态或凝视|紧裁局部：202206触觉、202210动物|原图细节与轮廓足够；裁切集中信息，不能损伤眼睛/手势意义，也不一定需要大面积展示字|
|一个人的处境|有环境线索的肖像与短主张：202006、202207|人物是报道核心且获得内页篇幅；原文/引语准确，不把路人变成虚构受访者|
|群体与多样性|多幅人像组成一个焦点：201911|统一共同问题与层级，保留不同身份，不拿无关人像填格|
|形态差异或材料集合|异尺度标本与留出的字场：202005|对象共同服务同一命题；图片大小不伪装成同比例，保留一处主导形态|
|需要揭示的隐藏关系|空间剖开、研究复原或概念场景：201912、202108、202110|必须有资料支撑具体结构；AI可表现绘画和材质，不能发明文物、内部或测量证据|
|短词本身能承载主题|图像进入巨大字形：202103|主标题极短、字形仍易认；中文用完整字形设计蒙版，不挤窄汉字；字内影像不能损害辨识|
|差异本身就是故事|有共同观察方式的照片条带：202107|同字段比较提供真实信息；只有几张无关风景时不采用，不无痕伪造连续街道|
|两种有据的概念方向|同一对象的双情景：202004|概念属性清楚，画面与内页讨论对应；不把想象情景当作真实前后照片|
|环境本身有力量|大面积天空/留白与克制短题：202208|空白形成尺度与情绪，主体足够有辨识度；不是所有封面都必须由大字占满|

风景、肖像、图鉴与概念封面都应承诺内页确实提供的内容。避免封面是一套炫目的生成世界，内页却没有对应研究或主题。
