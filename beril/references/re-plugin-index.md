## How to choose

- Start with the framework's built-in features before a plugin.
- Prefer a maintained plugin with a release and a version note.
- One plugin per job. Overlapping plugins fight over analysis.
- Verify every plugin output in the listing.
- Remove plugins you are not using. They slow analysis and widen the trust surface.
