# Approval table: matters and decision makers

The reader fills in and confirms this table for the project. The assignments below are drafting suggestions and do not take effect automatically.

| Matter | Who decides |
|---|---|
| Implementation details and fixes within existing authorization | Executing member |
| Quality and methods within a department | Department lead, or project manager if no lead is appointed |
| Project priorities, coordination across teams, and acceptance arrangements | Project manager |
| Spending and authorization scope | Human; follow existing authorization where it applies |
| Account credentials and actions requiring the person to act | Human |
| External releases and public commitments | Human |
| Irreversible deletion | Human |
| Project goals and direction | Human |
| Roles and working rules within that direction | Name the role authorized to decide this kind of change and the limits of its authority |
| Routine progress updates | Project manager summarizes; notification is not approval |
