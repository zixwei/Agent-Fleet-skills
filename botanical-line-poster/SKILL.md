# 植物学线描 x 平涂 x 美学提示词 (Botanical Line Poster)

## 风格提示词 (帖子原文, 逐字)

```text
将照片创作成3:4竖版上下双联海报：上半保持真实摄影风貌，下半以暖白纸底呈现日式极简图鉴海报。提炼照片中的核心主体、自然物件与标志性轮廓，将具象元素转译为大面积不规则纯色色块与精细黑色线描，以局部写实、整体抽象的虚实对比构建视觉焦点。采用现代日本版画语言、植物学线描、硬边平涂与细腻纸张肌理；依据原图色彩关系选取单一主色作为视觉锚点，辅以黑白中性色，通过高纯度色块与无彩线条形成克制对比。主体偏置放大，四周保留宽阔负空间，搭配粗体英文标题、日文标签、纤细网格线与角落传统纹样，形成理性秩序与东方侘寂相融合的瑞士网格编辑设计。
```

## 拆解 (照提示词, 方便替换变量)

- 画幅:3:4 竖版, 上下双联.上半 = 真实摄影风貌, 下半 = 暖白纸底的日式极简图鉴海报.
- 转译:提炼照片核心主体、自然物件、标志性轮廓, 具象元素转成大面积不规则纯色色块 + 精细黑色线描, 局部写实、整体抽象, 虚实对比做视觉焦点.
- 语言:现代日本版画、植物学线描、硬边平涂、细腻纸张肌理.
- 色彩:按原图色彩关系选单一主色做视觉锚点, 辅以黑白中性色, 高纯度色块对无彩线条, 克制对比.
- 构图:主体偏置放大, 四周留宽阔负空间, 粗体英文标题、日文标签、纤细网格线、角落传统纹样.
- 风格:理性秩序 (瑞士网格编辑设计) 与东方侘寂相融合.

## 作者方法论 (同作者 2026-11-21 帖子, 原话大意)

时间来到 2026 年底, 提示词逻辑不需要啰嗦太多, 而是多用"大词"或者方法论的词, 多用一些"术语".写提示词时优先堆风格术语与方法论词, 不要写成长篇大论.

## 何时用

照片转绘、植物 / 花卉 / 自然物件海报、日式图鉴风海报、双联海报时.把提示词交给生图模型 (作者当前用 Claude, 称"省心"), 主体与主色按原图换掉, 结构不动.

## 注意事项

- 上半必须保持真实摄影, 下半才是线描 + 平涂, 不要全图都画成插画.
- 主色只取一个, 从原图色彩关系里选, 不要多色堆砌.
- 传统纹样放角落, 不要铺满.
- 作者称其转绘项目将突破 500 个风格, 本条只收这一个 (植物学线描 x 平涂).
