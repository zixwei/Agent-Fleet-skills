# hairline 线稿动画 (2 技能)

从想法或 SVG 生成可交互等距线稿动画:画一个会回应指针的等距线稿图形,交出去就是一个自包含 HTML 文件.引擎在 `packages/hairline/src/`.

## 怎么用

- 新画一个图形:读 `skills/hairline-create/SKILL.md`.
- 把现成 SVG 改成 Hairline 图形:读 `skills/hairline-adopt/SKILL.md`.

## 收录清单

- [hairline-create](skills/hairline-create/SKILL.md):有想法要一个新 Hairline 图形时用;按想法画一个等距线稿图形,指针一碰就有反应,交出自包含 HTML 文件.
- [hairline-adopt](skills/hairline-adopt/SKILL.md):手头已有 SVG (图标、logo、插画),想把它变成 Hairline 图形时用;读图、按引擎重建、配一个回应指针的手势.
