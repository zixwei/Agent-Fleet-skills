# social-media-research-skills 社媒调研技能集 (13 技能)

教 AI 助手去扒 TikTok、Instagram、YouTube、Reddit、X 和 LinkedIn 上真正跑起来的帖子:找出一个账号里超平均的爆款,读评论挖出大家在问什么、在骂什么,把竞争对手和他们的广告拆开看.每个技能一份 SKILL.md,按 Agent Skills 规范写.

前提:需 ScrapeCreators API key (SCRAPECREATORS_API_KEY);没有 key 只能按方法论做分析,不能真去拉数据.

## 怎么用

按任务读 `skills/<名字>/SKILL.md`;不要一次全读,13 个技能只读当次要用的一个.

## 收录清单

- [ad-library-teardown](skills/ad-library-teardown/SKILL.md):拆 Meta/Google/LinkedIn 广告库里的在投广告,拆竞品话术,提 hooks、offers、CTA、视频转录、落地页 claim 与测试点子.
- [audience-research](skills/audience-research/SKILL.md):看创作者、红人、品牌受众:公开资料信号、TikTok 受众画像、粉丝/关注、评论、地域语言与内容匹配度,判断赞助与市场匹配.
- [comment-mining](skills/comment-mining/SKILL.md):挖评论与回复:受众反应、客户原话、问题、异议、抱怨、产品点子、购买意愿、情绪与 voice-of-customer.
- [competitor-social-research](skills/competitor-social-research/SKILL.md):研究竞品社媒策略,横向对比品牌/创作者,找赛道里跑得好的内容、内容缺口,出可执行的社媒策略简报.
- [content-repurposing](skills/content-repurposing/SKILL.md):把公开社媒视频、转录、帖子、创作者调研转成可复用内容资产:LinkedIn 帖子、X 串、短视频脚本、newsletter、博客大纲、轮播图、内容日历.
- [creator-profile-teardown](skills/creator-profile-teardown/SKILL.md):拆一个创作者、红人、创始人、品牌账号:定位、内容支柱、爆款、hooks、形式选择、受众反应,以及能抄、能测的东西.
- [influencer-prospecting](skills/influencer-prospecting/SKILL.md):在赛道里找创作者、红人、affiliate、社媒账号做外联、合作、赞助、UGC、种草或竞品调研,出打分后的 prospect 清单.
- [outlier-post-finder](skills/outlier-post-finder/SKILL.md):找相对创作者、品牌、竞品基线超平均的爆款帖子、视频、Reels、Shorts、推文,解释为什么跑起来,提 hooks 与形式,出 swipe file.
- [product-demand-research](skills/product-demand-research/SKILL.md):验证产品点子、找痛点、挖需求信号、找异议,从 Reddit、社媒帖子、视频转录与评论里收集 voice-of-customer 原话,出有证据的产品调研.
- [scrapecreators-api](skills/scrapecreators-api/SKILL.md):调 ScrapeCreators REST API 扒 27+ 社媒平台公开数据 (资料、帖子、视频、评论、转录、粉丝、广告、话题标签、热榜、互动数).
- [social-listening-brief](skills/social-listening-brief/SKILL.md):出社媒监听简报:品牌、人物、产品、话题、品类或赛道在公开社媒上的说法,带引用主题、情绪 caveat、重点帖子与建议动作.
- [transcript-intelligence](skills/transcript-intelligence/SKILL.md):总结、分析、复用 TikTok、Instagram、YouTube、Facebook、X、LinkedIn、Rumble、Reddit 视频转录:提 hooks、claims、quotes、内容原子、主题与可复用脚本.
- [trend-discovery](skills/trend-discovery/SKILL.md):发现赛道热门话题、标签、声音、帖子、Reels、Shorts、创作者或形式,按证据排序,把趋势转成可执行的选题角度.
